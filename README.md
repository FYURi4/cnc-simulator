3D‑редактор и симулятор для ЧПУ‑станков, написанный на Rust с использованием **wgpu** и **bevy_ecs**.  
Проект находится в активной разработке. Цель — создать интуитивный инструмент для подготовки и визуализации управляющих программ, похожий по удобству на Blender.

## ✨ Текущее состояние

Реализованы следующие возможности:

### Редактирование

- 🎯 **3D‑манипуляторы (Gizmo)** для перемещения, вращения и масштабирования — стрелки, кольца и кубы по осям X/Y/Z.
- 🧩 **Выделение подобъектов** (вершины, рёбра, грани) с поддержкой `Shift` для мульти‑выделения.
- 🎨 **Режим редактирования** (`EditMode::Edit`) с вычислением средней точки выделенных элементов в качестве пивота для Gizmo.
- 📐 **Ограничение трансформации по осям** — клавиши `X`, `Y`, `Z` во время перемещения, вращения или масштабирования.
- 🧲 **Snap‑привязка** — к сетке, шагу, началу координат, вершинам и рёбрам (`SnapSettings`: `Increment`, `Grid`, `Origin`, `Vertex`, `Edge`).
- ↩️ **История трансформаций (Undo/Redo)** — интеграция с `History`, откат и повтор через `Ctrl+Z` / `Ctrl+Y`.
- 📋 **Копирование, вставка и дублирование** — `Ctrl+C`, `Ctrl+V`, `Ctrl+D`.
- ☑️ **Выделение всех объектов** — `Ctrl+A`.

### Навигация и вид

- 🖼️ **Режимы просмотра** — Top / Front / Right / Iso через `Numpad 1 / 3 / 7 / 5`.
- 🔍 **Frame Selected** — `F` или `NumpadDecimal` для фокусировки камеры на выделении.

### Симуляция ЧПУ

- 📄 **Загрузка и визуализация G‑code** — базовая поддержка парсинга и отображения траекторий инструмента.

### Архитектура

- 🏗️ **ECS на `bevy_ecs`** и **рендеринг через `wgpu`**.

> [!WARNING]
> Проект не является готовым продуктом. Часть функций из [дорожной карты](#-дорожная-карта) ещё не реализована.

## 🗺️ Дорожная карта

| Этап | Функциональность | Статус |
|:---:|------------------|--------|
| 1 | X/Y/Z — ограничение перемещения по осям | ✅ **Реализовано** |
| 2 | Numeric Input — ввод точного значения с клавиатуры | ❌ Не реализовано (поля подготовлены, логики ввода нет) |
| 3 | Snap — привязка к сетке и шагам | ✅ **Реализовано** |
| 4 | R — полноценное вращение объекта | 🟡 Частично (есть режим и Gizmo вращения) |
| 5 | S — масштабирование объекта | 🟡 Частично (есть режим и Gizmo масштабирования) |
| 6 | Undo/Redo — интеграция трансформаций с историей | ✅ **Реализовано** |
| 7 | Pivot System — изменение точки вращения и масштабирования | 🟡 Частично (пивот = средняя точка выделения) |
| 8 | Local/Global — локальные и мировые координаты | ❌ Не реализовано |
| 9 | Advanced Gizmo — полноценные манипуляторы Blender | 🟡 Частично (базовые оси и кольца есть) |
| 10 | Multi-Selection — трансформация нескольких объектов | 🟡 Частично (выделение есть, трансформация — нет) |

**Легенда:** ✅ Реализовано · 🟡 Частично · ❌ Не реализовано

## 🎮 Управление

| Клавиши | Действие |
|---|---|
| <kbd>G</kbd> | Перемещение (Move) |
| <kbd>R</kbd> | Вращение (Rotate) |
| <kbd>S</kbd> | Масштабирование (Scale) |
| <kbd>X</kbd> / <kbd>Y</kbd> / <kbd>Z</kbd> | Ограничение трансформации по оси |
| <kbd>Shift</kbd> + клик | Мульти‑выделение |
| <kbd>Ctrl</kbd> + <kbd>A</kbd> | Выделить всё |
| <kbd>Ctrl</kbd> + <kbd>C</kbd> / <kbd>Ctrl</kbd> + <kbd>V</kbd> | Копировать / Вставить |
| <kbd>Ctrl</kbd> + <kbd>D</kbd> | Дублировать |
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> / <kbd>Ctrl</kbd> + <kbd>Y</kbd> | Undo / Redo |
| <kbd>Numpad 1</kbd> / <kbd>3</kbd> / <kbd>7</kbd> / <kbd>5</kbd> | Front / Right / Top / Iso вид |
| <kbd>F</kbd> или <kbd>NumpadDecimal</kbd> | Frame Selected |
| <kbd>Esc</kbd> | Отмена текущей трансформации |

## 🚀 Сборка и запуск

Убедитесь, что у вас установлен [Rust](https://rustup.rs/) (рекомендуется версия **1.70** или новее).

```bash
git clone https://github.com/FYURi4/cnc-simulator.git
cd cnc-simulator
cargo run --release
```

> [!TIP]
> Для быстрой итерации во время разработки используйте `cargo run` без `--release`.
